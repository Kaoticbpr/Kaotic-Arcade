# Scripts (Bazzite)

| Script | What it does |
|---|---|
| `arcade-rotate.sh` | switch the whole arcade between landscape and portrait (`portrait left|right`, `landscape`, `status`) |
| `arcade-rotate-button.py` | hold both flipper buttons 5 s in ES-DE to rotate (service; arm with `~/.config/arcade-rotate-button.armed`) |
| `portrait-switch.py`, `gen-arcade-rotated.py` | swap pinball and vertical arcade configs for portrait |
| `steam-menu-focus.py` | pauses ES-DE/game input while a Steam menu is open |
| `arcade-backup.sh` | one archive of all settings (no games/ROMs); keep it private, it contains your ES-DE settings |
