# Sounds

Every `.wav`, `.ogg` or `.mp3` in here (including subfolders) is built into the table, named after the
file. Names must be unique across all folders.

| Folder | What |
|---|---|
| `voice/` | Host callouts, `vo_<event>_<n>`; see [../VOICE_SCRIPT.md](../VOICE_SCRIPT.md) |
| `music/` | `music_theme`: the Yo! Retro theme, looped during play |
| `.` | Effects (flippers, bumpers, targets ...); the names the script uses are listed in [../DESIGN.md](../DESIGN.md) |

Only add audio you own or have permission to share: the table gets published.
