# Table list

Every Visual Pinball table in the KaoticBPR Arcade, with where to get it and the ROM it needs.

**Nothing here is included in the kit.** Tables, backglasses and wheel art belong to their authors and ROMs are copyrighted —
download each from the links below (a free VPUniverse / VPForums account is needed) and give the authors a thumbs-up.
Then add a table with `bazzite/add-table.sh` (Linux) or the **Pinball Table Installer** (Windows).

Legend: **ROM** = the PinMAME ROM zip the table asks for (`—` = no ROM, the table runs on its own script).
"Search" links open a VPUniverse search because I didn't record the exact page — pick the newest VPX table from the listed author.

## Per-table notes
- **Theatre of Magic** – on Linux the table script stops at line 176 (captive ball). Fix in [docs/LINUX-FIXES.md](docs/LINUX-FIXES.md). If the DMD says *Incorrect U22*, turn on "skip startup tests" (also in that doc).
- **The Walking Dead** – the table has its own DMD in the room; hide the backglass and put the score display over the built-in one (LINUX-FIXES.md).
- **Metallica Remastered** – uses the DMD built into the background; turn the kit's backglass and score display off for this table.
- **Total Nuclear Annihilation** – needs its PuP pack (videos) and is loud out of the box; lower its PuP volume.
- **Scared Stiff** – the script asks for ROM `SS_15` in upper case; on Linux, colour files must match that case (LINUX-FIXES.md).
- **Twilight Zone (Bigus 3.0)** – ships as the table file only; the script is inside it, so **do not keep an old `.vbs` next to it** (an old side script would override the new one). We run it with the alt sound turned off (remove or rename `pinmame/altsound/tz_94h`).
- **Tales of the Arabian Nights** – designed for the desktop view; use `BGSet = 0` in its settings file (a leftover cabinet rotation made it appear sideways in landscape). Its DMD sits in the black box built into the background (top left of the screen).
- **Theatre of Magic** – the Legends Unchained build wants both ROMs `tom_14hb` and `tom_13`; if the DMD still says *Incorrect U22*, reset the table's saved settings (NVRAM) for `tom_14hb`.
- **Landscape vs portrait:** every table has a landscape settings file and a portrait one (see [docs/BAZZITE.md](docs/BAZZITE.md), "Portrait mode"). Install and update tables in landscape mode.
