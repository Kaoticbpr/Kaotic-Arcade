# X-Arcade setup (PC host + VPX)

Profile for the X-Arcade Arcade2TV-XR mod: EmulationStation plus Visual
Pinball X standalone on a Windows, Linux or Mac host. See `CLAUDE.md` for
details and working rules.

```
xarcade-pc/
├── CLAUDE.md            # host facts + rules Claude Code follows here
├── machine.env.example  # copy to machine.env and fill in (git-ignored)
├── controls/            # X-Arcade mode + key map, per-app bindings
├── emulators/           # RetroArch / ES-DE settings
├── gamelists/           # curated gamelist.xml per system
├── vpx/                 # VPX config + table list (no table files)
└── backups/             # local snapshots (git-ignored)
```

Open Claude Code in this folder and work through the "First setup checklist"
in `CLAUDE.md`.
