# Kaotic-Arcade
X-arcade enabled solution with Windows/Linux/Mac based systems using emulation station and VPX standalone. Currently in development for users to have complete and seamless control of all their arcade and pinball needs using their x-arcade Arcade2tv-xr.

## Profiles

Each setup is a separate mod with its own folder under `profiles/`:

| Profile | Setup |
|---|---|
| [`xarcade-pc`](profiles/xarcade-pc/) | X-Arcade Arcade2TV-XR on a Windows/Linux/Mac host with EmulationStation + VPX standalone |
| [`iconic-sf2-pi5`](profiles/iconic-sf2-pi5/) | Iconic Street Fighter II cabinet (Raspberry Pi 5), managed over SSH |

Open Claude Code inside a profile folder to work on that setup; its `CLAUDE.md`
holds the device details and rules.
