==================================================================
  INSTALL GUIDE  -  X-Men '97 Arcade1Up Cabinet Expansion v2
==================================================================

Read this once before starting.  The whole thing takes about
20 minutes, most of which is waiting for files to copy.

You need:  the cabinet, a USB KEYBOARD and a MICRO-USB DATA CABLE.
No internet connection is needed - the emulator cores are included.


------------------------------------------------------------------
STEP 1  -  TURN ON USB DEBUGGING  (one time only)
------------------------------------------------------------------
A stock cabinet has ADB switched off, so your PC cannot talk to it
until you do this.  This is what the USB keyboard is for.

There is no Android home screen or app drawer on this cabinet -
none is installed.  X-Men '97 IS the home screen, so
pressing the Windows key on its own just puts you back in the game.
The way in is the notification shade:

  1.  Turn the cabinet on and let it boot into X-Men '97.
  2.  Plug the USB keyboard into the USB port on the back.
  3.  Press  WINDOWS + N.
      This pulls down the Android notification shade over the game.
  4.  Navigate to the SETTINGS COG in the shade and open it.
      That is your way into Android Settings - there is no other.
  5.  Open  About tablet.  Find "Build number" and press ENTER on
      it SEVEN times.  It will say "You are now a developer".
  6.  Go back one screen.  Open  Developer options.
  7.  Turn ON  "USB debugging".

      You do NOT need to change "Select USB Configuration". The
      installer works entirely over adb and never uses MTP.

  That is the only thing the keyboard is needed for. Everything
  after this happens from your PC.


------------------------------------------------------------------
STEP 2  -  CONNECT THE CABLE
------------------------------------------------------------------
Plug the micro-USB DATA cable from your PC into the cabinet's
micro-USB port on the back of the PCB.

  *  It must be a DATA cable.  Many phone-charger cables carry
     power only.  If nothing shows up, try a different cable first
     - this is the single most common problem.
  *  Plug straight into the PC, not through a USB hub.

The first time you connect, the CABINET SCREEN shows a popup:
      "Allow USB debugging?"
Use the keyboard (TAB / arrow keys / ENTER) to tick
"Always allow from this computer" and choose ALLOW.


------------------------------------------------------------------
STEP 3  -  ADD YOUR ROMS   (optional but recommended)
------------------------------------------------------------------
Open the  roms  folder in this package and read
PUT-YOUR-ROMS-HERE.txt.  Copy whichever of those ROM files you
own into that folder.

Then run  VERIFY-ROMS.bat  to check them.  It opens every zip and
compares each file inside against the sets known to work on a real
cabinet, and names anything that is missing or the wrong version.
This is the quickest way to find a bad download before it turns
into "the game will not load" later.

You can skip this and the mod will still install - you just will
not have any of the 20 extra games until you add ROMs and run the
installer again.


------------------------------------------------------------------
STEP 4  -  RUN THE INSTALLER
------------------------------------------------------------------
Windows :  double-click  INSTALL.bat
macOS   :  open the  mac  folder and read HOW-TO-RUN.txt

It will:
    install the three menu apps and RetroArch
    copy your ROMs to the cabinet
    copy the settings and NAOMI save files
    make the menu the boot screen
    turn on the LIVE button and the 2-player bridge

Do not unplug while it runs.  It ends with SUCCESS.


------------------------------------------------------------------
STEP 5  -  REBOOT AND PLAY
------------------------------------------------------------------
Reboot the cabinet.  It boots into the menu.

  Joystick LEFT / RIGHT      choose a cabinet
  Any action button          select
  EXTRA GAMES tile           the 20 extra games
  1P START                   start the highlighted game
  2P START                   go back
  Hold LIVE for 3 seconds    quit any game, back to the menu

Player 1 and Player 2 both work in every game.


------------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------------
I cannot get out of the game to reach Settings
    WINDOWS + N on a USB keyboard pulls down the notification
    shade, and the settings cog is in there. Pressing the Windows
    key by itself does nothing useful - X-Men '97 is the
    home screen, and no app drawer is installed on this cabinet.

"No cabinet detected"
    Wrong cable (most likely), USB debugging not on, or plugged
    into a hub.  Try another cable and a rear USB port on the PC.

"unauthorized"
    Look at the cabinet screen for the "Allow USB debugging?"
    popup and accept it with the keyboard.

A game says it cannot load content
    Usually a ROM problem rather than the emulator - run
    VERIFY-ROMS.bat.  The cores are installed by INSTALL.bat and
    live in /data/local/tmp/cores.

Guilty Gear X or Power Stone say "cannot load BIOS naomi"
    Your naomi.zip is almost certainly fine.  That message means
    Flycast could not FIND the file, not that it is wrong.  It has
    to exist in BOTH of these places:
        /sdcard/RetroArch/system/naomi.zip
        /sdcard/roms/naomi.zip
    Flycast looks for the NAOMI BIOS next to the game as well as
    in the system folder.  Put naomi.zip in this package's roms
    folder and re-run INSTALL.bat, which copies it to both.
    (Do not go hunting for a different naomi.zip - that is a dead
    end, and we wasted a lot of time on it so you do not have to.)

The buttons are in the wrong order on a Neo Geo game
    Re-run INSTALL.bat.  Those games use per-game remap files from
    config/remaps; without them the emulator puts A and B on the
    bottom row.

The extra games have no sound
    Re-run INSTALL.bat; it re-copies config/cabinet.cfg, which is
    what enables audio.

Guilty Gear X or Power Stone hang on a black screen
    Same fix.  Those two need  audio_sync = "false"  in
    cabinet.cfg, which the installer copies for you.

The LIVE button stopped working
    Re-run INSTALL.bat.  It re-arms the accessibility service that
    the LIVE button depends on.  After that it survives reboots on
    its own.

Two-player does not work on the extra games
    The bridge service must be running.  Re-run INSTALL.bat, or
    just reboot the cabinet - it starts automatically at boot.

I want my cabinet back to normal
    Run UNINSTALL.bat.
